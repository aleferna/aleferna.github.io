This is an example post. Blog posts live in `src/content/blog/` as Markdown files. The file name becomes the URL, so this one is served at `/blog/hello-world/`.

## Writing a post

Each post starts with a small block of metadata:

```yaml
---
title: "Post title"
description: "One-sentence summary shown in search results."
date: 2026-10-27
tags: ["research", "notes"]
draft: false
---
```

Set `draft: true` to keep a post visible in local development but out of the published site.
